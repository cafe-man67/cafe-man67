把這趟法國，
慢慢寫回來。

從諾曼第的海開始，後來走進巴黎、咖啡館、教堂、博物館與街道。這裡不是景點清單，而是把真正留下來的畫面與感受，一站一站整理成可以回去重看的旅行記憶。

進入法國旅記

這不是行程表，是回憶的索引。

旅行當下忙著走、忙著看，很多感受反而是在回來之後才慢慢長出形狀。CAFEMAN 先從巴黎開始，把每一站的照片、故事、文化與當時的心情整理成可以長久留下來的頁面。

01 Normandie / Étretat

第一站，象鼻海岸：把自己走進諾曼第的藍

天空很藍、時間很短。平常練過的腿終於在旅行裡派上用場，也讓我知道崖頂那條路其實還很長。

閱讀這一站 → 02 Normandie / Mont-Saint-Michel

聖米歇爾山：原來天使，也可以帶著劍

藍天、大潮、一路向上的石階；到了這裡，我才真正理解山頂那位米迦勒為什麼手裡拿著劍。

閱讀這一站 → 03 Bretagne / Saint-Malo

聖馬洛：原來「海盜」也有國王授權

走進城牆內老城，從私掠者、石板街到主教座堂，也在海鷗聲裡買下旅途中那隻海鷗娃娃。

閱讀這一站 → 04 Paris / Café

三十年後，我終於坐在雙叟

一本《叫咖啡的地方》留下的憧憬，隔了大約三十年，終於變成桌上的一杯咖啡。

閱讀這一站 → 05 Paris / Café

在花神，把自己定格在巴黎街角

排到戶外座位，看著車流與人潮，喝咖啡、吃三明治，也讓自己暫時不走。
